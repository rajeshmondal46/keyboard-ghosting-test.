# Keyboard Ghosting Test

A free browser-based tool for checking keyboard ghosting, multiple-key input, and rollover behavior.

## What is keyboard ghosting?

Keyboard ghosting happens when some key combinations are not registered correctly when several keys are pressed at the same time.

This can matter during gaming, fast typing, keyboard shortcuts, or any situation where multiple simultaneous key presses are important.

## What you can test

- Multiple keys pressed at once
- Keyboard ghosting
- Simultaneous key detection
- Gaming key combinations
- Basic rollover behavior
- Maximum detected keys

## Try common gaming combinations

You can test combinations such as:

- `W + A + Shift`
- `W + D + Space`
- `W + A + Shift + Space`
- `Ctrl + Shift + Space`

If one of the keys does not register, your keyboard may have a hardware or rollover limitation.

To check how many keys your keyboard can register at once, try this [keyboard ghosting test](https://www.keyboardtest.org/keyboard-ghosting-test.html).
